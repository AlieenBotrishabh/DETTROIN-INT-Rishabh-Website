## 🛠️ Technologies Used

- **Frontend Core**: React 18, JSX, JavaScript ES6+
- **Build Tool & Server**: Vite 6.0
- **Deployment & SPA Routing**: Vercel Production CLI & SPA Configuration (`vercel.json` rewrites & cache control)
- **Styling & UI System**: Custom Vanilla CSS Design System with CSS Custom Properties, Playfair & Outfit Typography, Advanced Glassmorphism, Shimmer Animations, Spring Transitions & Responsive Utilities
- **Icons & Visuals**: Lucide React Icon Pack
- **Interactive FX**: Canvas Confetti (Celebration animation on admission submission)
- **Typography**: Google Fonts (*Plus Jakarta Sans*, *Outfit*, & *Playfair Display*)

## ✨ Key UI/UX Improvements Made

1. **Modern Header & Accessible Navigation**:
   - Rotating Live Announcement Ticker (`Admissions Open 2026-27`).
   - Sticky navbar with high-contrast logo badge and animated dropdown menus.
   - Accessibility font-size resizer (`A- / A / A+`) and Dark/Light Mode toggle with `localStorage` state persistence.
   - Mobile sliding navigation drawer.

2. **Hero Section & Interactive Action Cards**:
   - Cinematic hero banner carousel with shimmer headlines, trust badges, and motivational taglines.
   - Quick action floating buttons for *Online Admission*, *Fee Calculator*, *Virtual Tour*, and *CBSE Board Results*.
   - Animated trust metrics counter (2,500+ Active Students, 100% CBSE Pass Rate, 50+ Smart Classrooms & Labs).

3. **About & Leadership Philosophy**:
   - Principal Dr. Sunita Sharma's message card with credentials.
   - Interactive tabs for *Principal's Desk*, *Vision & Mission*, and *Core Pillars*.
   - CBSE Affiliation #2132415 and ISO 9001:2015 accreditation badges.

4. **Student Success Stories & Board Results**:
   - Interactive Testimonials Carousel with student/parent quotes and ranks.
   - Subject-Wise Average Performance table with animated progress bars for CBSE Board Exams 2025.

5. **Academic Spectrum & STEM AI Lab Hub**:
   - Interactive academic wing explorer: Pre-Primary (KG), Primary (Grades 1-5), Middle (Grades 6-8), and Senior Secondary (Grades 9-12 Science/Commerce/Humanities).
   - Dedicated spotlight on Krishna Artificial Intelligence & Robotics Innovation Lab with IoT, 3D Printing, and Drone Tech features.

6. **Campus Facilities & 360° Virtual Tour**:
   - Grid layout featuring Robotics Labs, Olympic Swimming Pool, Smart Classrooms, Grand Library, Science Labs, and GPS Transport.
   - Interactive Facility Modal providing detailed descriptions and safety metrics.

7. **Interactive Multi-Step Admission Portal**:
   - Step 1: Student Information -> Step 2: Parent Details -> Step 3: Grade Selection & Document Upload Simulator -> Step 4: Submission Confirmation & Confetti Celebration.
   - Generates instant application reference numbers (e.g. `KIS-2026-849201`).

8. **Dynamic Tuition & Transport Fee Calculator**:
   - Select grade level, bus route zone, and boarding hostel options for instant quarterly, bi-annual, or annual breakdown.
   - Itemized PDF quotation slip generator.

9. **Media Gallery with Lightbox Viewer**:
   - Category filter pills (*All*, *Academics*, *STEM*, *Sports*, *Cultural*, *Campus*).
   - Modal Lightbox for full-screen photo viewing with date badges and descriptions.

10. **Events Calendar & CBSE Circular Downloads**:
    - Upcoming campus events list with dates, venues, and descriptions.
    - Downloadable CBSE circulars and official notices.

11. **Student & Parent Digital Portal Login Modal**:
    - Simulated login portal with role toggle.
    - Displays student dashboard metrics (Attendance 96.4%, Grade A1 Report Card, Issued Books, Cleared Dues).

12. **Contact Section, Map & FAQ Accordion**:
    - Functional contact form with live validation and success notification.
    - Embedded Google Map view.
    - Frequently Asked Questions accordion for instant parent support.

13. **Keyboard Shortcuts & Utilities**:
    - Press `Ctrl+K` (or `Cmd+K`) anywhere to open the Instant Search modal.
    - Press `Esc` to close any open modal window.
    - Floating Smooth Scroll-to-Top button.

## 💻 Local Setup & Development Instructions

```bash
# 1. Clone the repository
git clone https://github.com/AlieenBotrishabh/DETTROIN-INT-Rishabh-KrishnaInternationSchool.git

# 2. Navigate to project directory
cd DETTROIN-INT-Rishabh-KrishnaInternationSchool

# 3. Install dependencies
npm install

# 4. Start development server
npm run dev

# 5. Build for production
npm run build
```
